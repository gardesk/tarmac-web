# Workspaces

tarmac provides 10 numbered workspaces per monitor, plus named special workspaces (scratchpads) that can be toggled as overlays.

## Overview

Workspaces are virtual desktops. Each workspace has its own BSP tree with its own set of tiled and floating windows. Only one workspace is visible per monitor at a time.

When you switch workspaces, tarmac hides the windows of the current workspace and shows the windows of the target workspace using the SkyLight framework.
